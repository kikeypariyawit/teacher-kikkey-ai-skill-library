# bev-parent-copywriter

## Purpose

Write persuasive, warm, credible Thai parent-facing copy for BEV that feels human, specific, and education-first rather than salesy.

## Use when

Use for BEV captions, ad copy, invitations, landing-page sections, parent replies, and promotional descriptions.

## Required inputs

- Offer/activity
- Parent concern or desired outcome
- Proof/activity details
- CTA goal
- Tone/length

## Workflow

1. Start from the parent's lived situation, not the brand.
2. Name one concrete tension, desire, or observation in natural Thai.
3. Show what the child actually does, sees, says, solves, or experiences.
4. Translate activities into plausible benefits without overclaiming.
5. Use English phrases only where they add authenticity or demonstrate language use.
6. Make the invitation feel like the natural next step rather than a hard sell.
7. Write one specific CTA.

## Output contract

- Primary copy
- Optional headline
- Optional short CTA
- Optional English line

## Final QA

- Natural Thai
- No guilt-heavy manipulation
- No exaggerated promises
- Concrete details
- Clear next action

## Operating rules

- Preserve explicit user constraints over defaults in this skill.
- Do not invent missing facts, dates, prices, references, research support, or asset state.
- Prefer concrete decisions and finished outputs over generic advice.
- Keep the result easy to hand off to the next skill.
- If an external action needs an unavailable tool or permission, complete every possible upstream step and state the blocked action clearly.
