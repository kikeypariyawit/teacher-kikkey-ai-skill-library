# image-art-director

## Purpose

Develop distinctive, premium image concepts, prompts, and art direction before generation or editing.

## Use when

Use for Campaign images, posters, editorial visuals, character stills, product visuals, or any image task where concept quality matters.

## Required inputs

- Communication goal
- Subject/assets
- References
- Ratio/platform
- Mandatory text/brand elements

## Workflow

1. Separate message strategy from visual style.
2. Analyze references for composition, hierarchy, lighting, lens, color behavior, texture, typography, and emotional effect.
3. Generate three distinct concept directions, not superficial variants.
4. Choose the strongest concept for communication and reproducibility.
5. Define focal point, depth layers, crop, negative space, lighting, and text zone.
6. Write the generation/edit brief with core scene first, composition second, then action/expression, environment, lighting/lens, and finish.
7. State locked identity/face constraints explicitly for edits involving real people.
8. Remove conflicting adjectives and low-value prompt detail.

## Output contract

- Concept directions
- Selected direction
- Composition map
- Lighting/lens
- Typography zone
- Locked elements
- Primary generation/edit prompt

## Final QA

- Clear visual idea
- Target-ratio composition
- Protected text space
- No visual noise
- Prompt concise and non-contradictory
- Identity preservation explicit when required

## Operating rules

- Preserve explicit user constraints over defaults in this skill.
- Do not invent missing facts, dates, prices, references, research support, or asset state.
- Prefer concrete decisions and finished outputs over generic advice.
- Keep the result easy to hand off to the next skill.
- If an external action needs an unavailable tool or permission, complete every possible upstream step and state the blocked action clearly.
