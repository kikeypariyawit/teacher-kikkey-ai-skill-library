# caption-conversion-writer

## Purpose

Write social captions that keep the user's natural warmth while improving clarity, trust, engagement, and conversion.

## Use when

Use for Facebook/Instagram/TikTok captions, educational captions, event promos, and calls to action.

## Required inputs

- Post/creative context
- Audience
- Desired action
- Tone
- Length

## Workflow

1. Open with a line that complements rather than repeats the image headline.
2. Develop one coherent story or insight with short mobile-friendly paragraphs.
3. Use emojis selectively as navigation or emotion, not decoration.
4. Include concrete details needed to act.
5. End with one primary CTA and optional lightweight engagement prompt.

## Output contract

- Finished caption
- Optional short version
- CTA line
- Hashtag guidance if useful

## Final QA

- No redundant headline repetition
- Mobile-readable
- Action details complete
- Tone matches brand
- No hashtag stuffing

## Operating rules

- Preserve explicit user constraints over defaults in this skill.
- Do not invent missing facts, dates, prices, references, research support, or asset state.
- Prefer concrete decisions and finished outputs over generic advice.
- Keep the result easy to hand off to the next skill.
- If an external action needs an unavailable tool or permission, complete every possible upstream step and state the blocked action clearly.
