# BEV visual execution

Use this for new images, broad redesigns or a complaint that the result looks generic. For a narrow correction use the existing production-and-revisions guide.

## Make a compact direction card before generation

Keep this working card internal unless the user requests it:
- Message: one concrete thing the parent should understand.
- Source roles: each accessible file and what it owns (logo, photo, edit target, style only).
- Hero: specific visible action, expression or object; intended crop and scale.
- Composition: focal location, reading path, clean text area and safe edges.
- Copy: exact headline, supporting line, required facts and optional CTA.
- Treatment: palette roles, light character, type weight, one motif if needed.
- Invariants: face, expression, anatomy, clothing, equipment, logo and confirmed facts.
- Delta: what this revision is allowed to change.

Do not send every available image as a reference. Bind only assets with a clear job. A generated poster cannot establish the identity of a real child. A similar logo in a reference is not the original logo.

## Use the source's strengths

For real-photo work, rank available candidates by understandable action, expressive moment, useful crop, light and image quality. Choose the strongest story, not simply the sharpest smile. Do not direct a new facial expression or smoother skin to make documentary children look better. Preserve original photos with an allowed layout method when exact preservation is required; explain actual generative limits.

If the user supplies only a collage, assess whether each crop has sufficient detail; prefer an accessible original when needed. Do not invent detail or claim a crop has original resolution.

Extract likes and dislikes precisely from user feedback: keep warm light, remove side slogans; keep energetic subject, simplify price area. Do not treat all source decoration as endorsed merely because the user supplied it. Do not infer whether an unknown image is generated solely from its appearance.

## Make three different compositions, then choose

Compare internally:
1. A hero-dominant design.
2. A type- or object-led design.
3. A sequence or asymmetric design.

These are options, not three compulsory outputs. Select by message, authentic assets and mobile readability. Let available photos rule out unsuitable options. For an intentionally rich fantasy event, preserve its energy while reducing competing hierarchy; do not flatten every campaign into cream minimalism.

## Control density and typography

For a general single feed post, start with one short headline and at most one supporting sentence. Treat this as a starting point, not a hard limit on a user-requested information poster. Group essential offers; move nonessential explanation to the caption. Never omit a required condition to look cleaner.

At approximately 360 px display width, the headline should read immediately, supporting copy should read without zoom, and the main action should be clear. Revise text length/line breaks before shrinking type. Use Thai shaping with available fonts, keep vowels/tone marks inside line boxes, and avoid manually spaced Thai letters. Do not invent a verified font choice when using image generation.

Maintain room around the original logo. Use no unverified QR. Respect ratio and orientation per image; resizing means recomposition rather than stretching.

## Write concrete image prompts

Structure: purpose → source roles → hero/action → composition → exact text → light/palette/type → invariants → permitted change → count/ratio.
Use actual spatial decisions instead of repeated words such as masterpiece, ultra premium or world-class.
For a change request, repeat only the relevant invariants and change scope. Do not pile dozens of stylistic demands onto a small correction.

Use the installed imagegen workflow and current tool contract. Do not claim that a skill changes the image model, enables a paid API or guarantees better images.

## Evaluate two separate gates

Correctness gate:
- Exact copy/facts; original logo; source identity; requested ratio/count; no unsafe equipment invention.
- Any material failure needs repair or a clearly stated limitation.

Craft gate:
- One convincing focal point and intelligible action.
- Readable Thai, intentional line breaks and no crowding.
- Natural color/light; no muddy green skin cast or excessive glow.
- Relevant decoration and a composition distinct from available recent designs.
- Caption and image express the same promise.

Keep a short internal observation → repair record using actual defects. Do not assign an unsupported 10/10 or say QA passed without seeing the image. Inspect the changed area and neighbors after a targeted repair, then stop. If the image tool provides no inspectable result, say what is unverified.

For a prompt-only task, evaluate the brief, not the nonexistent rendered image. For an installation test, distinguish text/structure tests from a real before-and-after image comparison.
