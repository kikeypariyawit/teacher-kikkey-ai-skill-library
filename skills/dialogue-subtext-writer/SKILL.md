# dialogue-subtext-writer

## Purpose

Write natural English dramatic dialogue with subtext, character voice, internal monologue, and playable emotion.

## Use when

Use for English dialogue, scene rewrites, monologues, voiceover, inner thoughts, confrontation, romance, comedy, or intense scenes.

## Required inputs

- Scene objective
- Characters/relationship
- What each knows
- Desired emotional turn
- Runtime

## Workflow

1. Define what each character wants from the other.
2. Separate spoken intention from hidden intention.
3. Write short playable lines with interruptions, evasion, silence, and action beats where natural.
4. Give each character distinct vocabulary, rhythm, directness, and defenses.
5. Use internal monologue only when it adds information or contradiction unavailable visually.
6. End dialogue after the scene turn; do not over-explain emotion.

## Output contract

- Dialogue script
- Internal monologue if needed
- Performance notes
- Subtext notes

## Final QA

- Characters sound different
- No exposition dump
- Lines speakable
- Emotion playable
- Subtext where appropriate
