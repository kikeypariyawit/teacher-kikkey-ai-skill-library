# bev-creative-director

## Purpose

Create premium, modern, high-converting visual directions for Bangyai English Village without generic AI-poster or cheap-template aesthetics.

## Use when

Use for BEV posters, campaign key visuals, social posts, ads, redesigns, layout direction, or image-generation briefs.

## Required inputs

- Required copy/offer
- Logo/brand assets
- Real photos/references
- Target ratio/platform
- Campaign objective

## Workflow

1. Classify references as content, brand, real-photo asset, style, or layout reference.
2. Extract non-negotiable facts and separate them from decorative copy.
3. Develop three genuinely different art directions.
4. Select the strongest direction for hierarchy, emotion, readability, and brand fit.
5. Design one dominant focal point and one clear reading path.
6. Use typography, spacing, crop, lighting, and graphic elements intentionally; reduce clutter.
7. Preserve real child identity and original faces whenever supplied photos are used; never substitute generated children for real-photo requirements.
8. Run surgical QA for logo, spelling, dates, prices, face integrity, hierarchy, crops, and mobile readability.

## Output contract

- Chosen art direction
- Composition hierarchy
- Typography direction
- Image treatment
- Generation/editing brief
- QA checklist

## Final QA

- Premium agency-level feel
- No generic Canva look
- No unnecessary badges/shapes
- Thai/English copy checked
- Required facts preserved
- Face/photo constraints respected

## Operating rules

- Preserve explicit user constraints over defaults in this skill.
- Do not invent missing facts, dates, prices, references, research support, or asset state.
- Prefer concrete decisions and finished outputs over generic advice.
- Keep the result easy to hand off to the next skill.
- If an external action needs an unavailable tool or permission, complete every possible upstream step and state the blocked action clearly.
