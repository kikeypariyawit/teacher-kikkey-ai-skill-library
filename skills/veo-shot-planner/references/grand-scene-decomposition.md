# Grand Scene Decomposition for AI Video

Use this when a set piece contains several high-complexity dimensions at once.

## Previs pass

Before prompts, write:
- geography objective
- emotional objective
- one hero image
- entry state
- exit state

Then build only the coverage necessary to connect them.

## Complexity vector

For each proposed shot classify:
- named identities
- crowd density
- body/contact choreography
- prop precision
- camera path
- environment motion
- VFX
- dialogue/audio
- exact landing state

If 4+ categories are high, split unless a known project test proves the route reliable.

## Decomposition patterns

### Pattern A — Grand arrival
1. wide environment master
2. subject entrance with foreground occlusion
3. medium reveal
4. reaction
5. hero close/medium

### Pattern B — Public confrontation
1. event geography
2. protagonist decision
3. opponent response
4. evidence insert
5. crowd/public consequence
6. aftermath

### Pattern C — Emergency / escape
1. threat geography
2. one movement objective
3. obstacle
4. decision
5. consequence
6. exit state

### Pattern D — Expensive quiet scene
1. authored environment
2. two-person spatial power frame
3. reaction hold
4. meaningful movement across distance
5. changed composition

## Continuity bridge tools

Use:
- match-on-action
- foreground wipe/occlusion
- reaction shot
- prop insert
- J/L cut
- sound bridge
- stable scene anchor
- return-to-wide

These can hide boundaries between separately generated clips.

## Start/end frames

Start frame:
- use for identity/composition/geography/state control.

End frame:
- use only for a required landing state.

For organic acting or walking, a forced end frame can reduce natural motion. Prefer a start-only route unless the destination is continuity-critical.

## Failure repair order

1. simplify camera
2. shorten action
3. reduce crowd specificity
4. separate interaction into coverage
5. strengthen start/location reference
6. remove unnecessary end frame
7. reroute model/tool after repeated failure
