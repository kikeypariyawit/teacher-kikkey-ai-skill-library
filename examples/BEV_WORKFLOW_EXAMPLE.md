# BEV campaign workflow example

Request: create a fresh parent-education post that can become a promotional creative.

Route:
1. `bev-content-strategist`
2. `bev-parent-copywriter`
3. `bev-creative-director`
4. `visual-qa`
5. `bev-campaign-qa`

Key rule: strategy → copy → visual direction → visual QA → campaign fact QA.
