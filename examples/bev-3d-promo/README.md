# BEV 3D Benefits Reel — "พาลูกออกจากจอ"

คลิปแนวตั้ง 9:16 · 1080×1920 · 30 fps · 24 วินาที · เรนเดอร์ด้วยโค้ด (three.js + Playwright + ffmpeg)
สร้างเมื่อ 2026-11-12

## ไฟล์

| ไฟล์ | คืออะไร |
|---|---|
| `film.html` | ทั้งคลิป: ฉากเกาะ 3D + ตัวหนังสือ + `window.seek(t)` เปิดในเบราว์เซอร์เพื่อดูพรีวิวได้ (ต้องเปิดผ่าน local server) |
| `render.js` | `probe` (ภาพทดสอบ) · `range` (เรนเดอร์เฟรม) · `encode` (รวมเป็น MP4) |
| `CHATGPT_IMAGE_PROMPTS.md` | ชุด prompt เจนภาพใน ChatGPT + ชื่อไฟล์ที่ต้องใช้ |
| `assets/gpt/` | วางภาพจาก ChatGPT ที่นี่ คลิปจะแสดงเป็นโพลารอยด์อัตโนมัติ |
| `POST_PACK.md` | บทพากย์ · sound map สำหรับ CapCut · แคปชั่น · ไอเดียคอนเทนต์ต่อ |

## เรนเดอร์ใหม่

```bash
npm install
node render.js probe 1 5 8.5 11.5 14.5 17.5 21     # ดูภาพทดสอบที่ out/probe/sheet.jpg
node render.js range 0 24 /tmp/bev_frames          # ~2–3 วิ/เฟรม (เพิ่ม --noimg ถ้าไม่เอาภาพ ChatGPT)
node render.js encode /tmp/bev_frames out/bev_3d_benefits_reel.mp4
```
