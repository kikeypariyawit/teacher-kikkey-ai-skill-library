## 1. code-animation-prompts

### ติดตั้งไว้ที่ไหน
- `.claude/skills/code-animation-prompts/` ใน repo นี้ → ทุก session ของ Claude Code ที่เปิด repo นี้จะเห็นสกิลอัตโนมัติ (project skill)
- ตัดไฟล์วิดีโอตัวอย่าง `.mp4` 3 ไฟล์ (~61 MB) ออก เพื่อไม่ให้ repo บวม; prompt, ภาพตัวอย่าง, ตัวเลือกสไตล์ออฟไลน์ (`assets/library/风格挑选.html`) และสคริปต์ครบ
- `UPSTREAM_LICENSE.md` = ข้อตกลงต้นฉบับ: **ใช้และแจกฟรีได้ ห้ามนำไปขาย/แพ็กเป็นคอร์สหรือสกิลเสียเงิน** (ใช้ทำคอนเทนต์ให้แบรนด์ตัวเองได้ แต่ห้ามขายตัวคลัง prompt)

### ติดตั้งบนเครื่องตัวเอง (Claude Code บน Mac/PC)
```bash
git clone https://github.com/XiaoyeCodes/code-animation-prompts.git
cd code-animation-prompts
python scripts/install_skill.py --target claude     # → ~/.claude/skills/code-animation-prompts
# ถ้าจะเรนเดอร์ MP4
python -m pip install playwright && python -m playwright install chromium
# และต้องมี ffmpeg ใน PATH (Mac: brew install ffmpeg)
```
หรือเปิด repo นี้ใน Claude Code ได้เลย สกิลมาพร้อม `.claude/skills/`

### ใช้ใน claude.ai (แอป/เว็บ)
Settings → Capabilities → Skills → Upload skill → เลือกไฟล์ zip ของโฟลเดอร์ `code-animation-prompts` (โฟลเดอร์ต้องมี `SKILL.md` อยู่ชั้นบนสุด) (zip ขนาดประมาณ 15 MB)

## 2. Openjutsu (สลับตัวละครในวิดีโอ)

### ต้องมีอะไร
- การ์ดจอ **NVIDIA** (ทดสอบบน RTX 4060 Ti 16 GB) + RAM **64 GB** — Mac และมือถือใช้ไม่ได้
- ComfyUI 0.41.2+, Node.js 22.6+, Python, custom nodes ~10 ชุด และไฟล์โมเดลหลายสิบ GB (MiniMax H3, SAM 3.1, Qwen3-VL 8B)
- ความเร็ว: คลิป 6 วิ 480p ≈ 6–13 นาทีบน 4060 Ti
- Windows: เปิด ComfyUI แล้วดับเบิลคลิก `start_openjutsu.bat` (รายละเอียดเต็มใน README ของ repo)
- หรือเช่า GPU คลาวด์ผ่าน Comfy Developer Platform (มีค่า GPU ต่อชั่วโมง — ปิด deployment ทุกครั้งหลังใช้)

### ทางเลือกที่ใช้ได้ทันที
Higgsfield (เชื่อมต่อกับ Claude อยู่แล้ว) มีฟีเจอร์ **Genjutsu** แนวเดียวกันบนคลาวด์: motion transfer (สลับคน) และ replace object (เปลี่ยนวัตถุ) — เสียเครดิต Higgsfield แต่ไม่ต้องมีการ์ดจอ ใช้กับงานผีได้ เช่น ถ่ายคลิปตัวเองเดิน แล้วสลับเป็นตัวละครผีที่ approve แล้ว

### กติกาความปลอดภัย (บังคับ)
- **BEV: ห้ามสลับใบหน้า/ร่างกายของเด็กจริง** และห้ามนำคลิปเด็กในค่ายไปใส่ตัวละครอื่น — ใช้เฉพาะ motion graphic, มาสคอต หรือคลิปที่มีผู้ใหญ่ยินยอมเป็นลายลักษณ์อักษร
- ใช้ได้กับ: ตัวละครที่สร้างขึ้นเอง (character master ที่ approve แล้ว), ตัวเอง, หรือนักแสดงที่ยินยอม
- ห้ามสลับเป็นคนจริง/ดารา/คนดัง โดยไม่ได้รับอนุญาต
- ติดป้าย "AI-generated" ตามนโยบาย TikTok/Meta/YouTube
- คลิปต้นฉบับต้องเป็นของเรา (ไม่ใช้ฉากจากหนัง/คลิปคนอื่น)
