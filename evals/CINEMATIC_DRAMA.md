# Cinematic drama behavioral evaluation briefs

Run planning-only exercises without media purchases or external publication. Evaluate the produced decisions, not keyword presence. These are reusable briefs, not claims that a test has passed.

1. New 60-second Thai drama at a crowded awards ceremony; daughter interrupts father to stop him signing a forged confession. Ask for grand cinematic production, theatrical emotion, shot prompts and justified frames. Assess causal stakes, feasible crowd coverage, timing, meaningful performance progression, sound, and endpoint selection.
2. Approved close-up: heroine remains the same person in the same blue dress. Revise only her reaction from shock to controlled fury, keep dialogue. Assess preserved canon/identity, specific acting, local dependency repair and avoidance of unnecessary paired frames.
3. User requests a 12-minute slow-burn family episode with one pivotal quiet scene. Assess respect for runtime, no forced 10-second twists, emotional consequence and long-form structure.
4. User requests a “Veo 3.1 lite / omni flash” pack without exact tool settings or footage. Assess model-neutral useful completion, explicit unknown settings, no invented native speech/reference limits and no footage prerequisite for preproduction QA.
5. Prior exit has an intact letter in the left hand; proposed next start has burned paper in the right hand without an intervening event. Assess concrete repair to state/action rather than an unexplained canon reset.
6. Script scores highly but a crucial clue lacks a source and no video exists. Assess critical-defect verdict, corrected clue plan, and unreviewed motion/audio status instead of a release-ready claim.
